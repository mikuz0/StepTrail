# План исправления: Hilt_StepTrailApp не генерируется

## Проблема
Приложение падает при запуске с ошибкой:
```
java.lang.ClassNotFoundException: Didn't find class "com.pandakind.steptrail.StepTrailApp"
Caused by: java.lang.ClassNotFoundException: Didn't find class "com.pandakind.steptrail.Hilt_StepTrailApp"
```

**Корень проблемы:** Hilt KSP процесс не сгенерировал `Hilt_StepTrailApp` для класса с аннотацией `@HiltAndroidApp`.

## Диагностика
- Каталог `app/build/generated/ksp/debug/java/` содержит только Room реализации (`WalkDao_Impl`, `AppDatabase_Impl`)
- Файл `Hilt_StepTrailApp.kt` отсутствует
- `StepTrailApp.kt` имеет аннотацию `@HiltAndroidApp` — должен запускать KSP для Hilt

## Возможные причины
1. **Конфликт версий:** Hilt 2.46.1 + KSP `2.0.21-1.0.28` может не работать корректно
2. **Порядок применения плагинов:** Hilt плагин должен применяться ПОСЛЕ Kotlin плагина
3. **Кэш Gradle:** Старый кэш может мешать генерации

## План исправления

### Шаг 1: Проверка порядка плагинов в `app/build.gradle.kts`
**Файл:** `app/build.gradle.kts`

Текущий порядок:
```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.compose)
    alias(libs.plugins.ksp)
    alias(libs.plugins.hilt)
    id("org.jetbrains.kotlin.android")  // ← ХОРОШО, Kotlin после Hilt
}
```

**Проблема:** Hilt плагин должен применяться ДО Kotlin плагина. Изменить порядок:
```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.hilt)  // ← Hilt ДО Kotlin
    alias(libs.plugins.kotlin.compose)
    alias(libs.plugins.ksp)
    id("org.jetbrains.kotlin.android")
}
```

### Шаг 2: Clean build
Выполнить последовательно:
```bash
./gradlew clean
./gradlew :app:assembleDebug --no-configuration-cache
```

### Шаг 3: Проверка сгенерированных файлов
После сборки проверить наличие:
```
app/build/generated/ksp/debug/java/com/pandakind/steptrail/Hilt_StepTrailApp.java
```

### Шаг 4: Установка на устройство
```bash
./gradlew :app:installDebug
adb shell am start -n com.pandakind.steptrail/.MainActivity
```

### Шаг 5: Если проблема сохраняется — проверить логи KSP
```bash
./gradlew :app:compileDebugKotlin --info 2>&1 | grep -i "hilt\|ksp"
```

## Критерии готовности
- [ ] `Hilt_StepTrailApp.java` сгенерирован в `app/build/generated/ksp/debug/java/`
- [ ] `./gradlew :app:assembleDebug` → BUILD SUCCESSFUL
- [ ] Приложение запускается на устройстве без `ClassNotFoundException`
- [ ] `adb logcat` не показывает FATAL EXCEPTION при старте

## Файлы для изменения
1. **`app/build.gradle.kts`** — изменить порядок плагинов (hilt перед kotlin)

## Файлы для проверки (не изменять)
- `app/src/main/java/com/pandakind/steptrail/StepTrailApp.kt` — должен иметь `@HiltAndroidApp`
- `gradle/libs.versions.toml` — проверить версии hilt и ksp
